# Media editing workspace

Mode: Operate. Extend Cutmark's native visual system; keep approved Plan, Record, Export, styles and recording guides unchanged.

## Direction contract

THESIS: Select real media, see it, then build an edit whose preview and export agree. The previous filmstrip-only editor is the functional baseline to replace.

OWN-WORLD: Existing Theme colours and sans typography, SF Symbols and Cutmark controls. Quiet surfaces, one accent for selection, visible track labels and time rulers. No new brand.

STORY: Browse session assets or import files, preview before inserting, assemble video/images, layer audio, trim and reorder clips, adjust speed/volume/framing, undo, export.

FIRST VIEWPORT: Media browser left, large preview centre, selected-clip controls right, persistent resizable timeline below. Main video and audio lanes have named controls. Export sits at top right. Compact windows collapse secondary panels rather than compressing clips.

FORM: Familiar video-first workspace, explicitly pinned by the user's Reelbird, Screen Studio and FocuSee references. Code-led extension of the existing app; no new visual-world roll.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
