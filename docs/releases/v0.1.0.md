# Cutmark 0.1.0

Cutmark 0.1.0 is the first public TriHerm Labs release of the local-first video production workspace created by Fernando Abishai.

## Highlights

- **Independent Cutmark identity:** `Cutmark.app`, bundle identifier `com.triherm.cutmark`, `~/Movies/Cutmark`, its own URL scheme, config, update channel, assets, and GitHub releases.
- **Provider-neutral setup:** choose Claude Code, Codex, pi, or opencode during first run. Cutmark does not silently install Claude Code.
- **Multi-provider in-app chat:** Claude Code, Codex, pi, and opencode are first-class runners. opencode conversations persist and resume their native session.
- **Direct MCP access:** Cutmark's MCP server can run over stdio or the MCP `2025-06-18` Streamable HTTP profile. ChatGPT does not require Codex as a bridge when custom MCP access is available.
- **Cutmark-native identity:** the MCP server is registered as `cutmark`, bundled skills use `cutmark-*`, and internal targets, helpers, and app metadata use Cutmark naming.
- **Cutmark-owned secrets:** auxiliary keys are written to `~/.config/cutmark/.env`. Legacy `~/.claude/.env` values are read only as a migration fallback.
- **Private by default:** the v0.1.0 release configures no usage analytics endpoint. The MCP HTTP listener binds to loopback by default.
- **Independent release path:** GitHub Actions tests, builds, packages, and releases `Cutmark.dmg` from the TriHerm repository.

## Platform

Cutmark 0.1.0 is a **macOS 15+ Apple silicon** release. The Cutmark iPhone companion source remains in the repository for future release work, but the phone bridge is disabled in this release.

## Signing

The open-source release artifact is ad-hoc signed and is not yet notarized. macOS may require **System Settings → Privacy & Security → Open Anyway** on first launch.
