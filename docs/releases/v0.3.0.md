# Cutmark 0.3.0

Cutmark 0.3.0 adds a visual, non-destructive timeline editor alongside more flexible screen recording and a faster path from capture to review.

## Recording

- **Three capture modes:** record camera, screen, or camera and screen together. Screen-only mode does not create a camera take.
- **Source selection:** choose a display or an application window for screen capture, with fail-closed behavior if a selected window disappears.
- **Recording controls:** keep the pre-record button fixed at the bottom center while the active recording controls can be moved.
- **Capture recovery:** preserve per-take recording claims and recover playable camera or screen media after interruption when possible.

## Visual timeline editing

- **Real cut preview:** review actual selected footage in a larger editing workspace with a filmstrip, audio waveform, time ruler, and draggable playhead.
- **Non-destructive operations:** trim, re-extend to the original source range, split, reorder, duplicate, remove and undo without altering the original recording.
- **Navigation:** scrub from the ruler or media lanes, zoom to fit and adjust timeline zoom. Extra workspace after the clip does not add blank seconds to the exported edit.
- **Screen recording compatibility:** handle sparse or variable-frame-rate screen captures using available source metadata instead of rejecting a playable clip solely because its minimum frame duration is unusual.
- **MCP editing:** support reviewed timeline plans, including trim extension, through the Cutmark integration.

## Review and updates

- **After-stop preview:** once a take is saved, a small lower-left preview offers playback, review, and an Edit action without duplicating the recording.
- **Check for Updates:** a visible manual command in both the Cutmark app menu and the in-app menu reports whether an update is available or verification failed; checking does not automatically install an update.

## Distribution and compatibility

- **Platform:** macOS 15 or later on Apple silicon. The iPhone companion is not part of this release.
- **Signing:** this release intentionally uses the existing **ad-hoc signed, non-notarized** distribution channel. The separate Developer ID/notarization workflow remains fail-closed for other future release tags.
- **macOS Gatekeeper:** first launch may require **System Settings → Privacy & Security → Open Anyway**.
- **Validation:** CI tests/build and a manual Cutmark Smoke R5 check passed before merging the editor changes. Not every camera, microphone, window, or multi-monitor hardware combination was exercised.

## Install

Download `Cutmark.dmg`, verify its SHA-256 against `SHA256SUMS`, open the disk image, and drag `Cutmark.app` into Applications. Updating may require granting camera, microphone, or screen-recording permission again because this release is signed ad-hoc rather than with a stable Apple Developer ID.
