# Cutmark 0.4.1

## Record and edit

- Fix a camera-preview race when switching between Camera and Screen + Camera.
- Open a screen recording and its camera as one linked take, keeping the source files separate. Use common microphone audio to refine alignment when the recordings contain a usable matching signal.
- Start editing on the first import, trim at the playhead, and export the current timeline directly from the editor.
- Reuse timeline thumbnails and waveforms during clip moves and keep the previous preview visible while the new one is prepared.
- Keep playhead changes made while the preview rebuilds instead of ignoring them.
- Keep the selected clip through Undo and Redo. After Delete, select a neighbor in the same lane; stop selecting clips when that lane is empty.

## GIFs inside Cutmark

- Open **Edit → Media → Find GIFs** to search Wikimedia Commons, preview animated GIFs, and add them to the timeline without leaving Cutmark.
- The catalog includes public-domain and CC0 animated GIFs. Save the source and license information alongside imported assets.
- Local GIF import remains available. Animation and transparency are preserved in the preview and MP4 export.

## Version and installation

- Fix local build version labels that incorrectly fell back to 0.3.0.
- Download `Cutmark.dmg` and verify its SHA-256 against `SHA256SUMS`. Open the disk image and drag Cutmark to Applications after saving your work and quitting the previous version.
- This release uses ad hoc signing without Apple notarization. On first launch, macOS may require **System Settings → Privacy & Security → Open Anyway**.
