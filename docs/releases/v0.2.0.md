# Cutmark 0.2.0

Cutmark 0.2.0 moves the editing system from timing infrastructure into evidence-driven screen editing, while hardening how public builds are delivered and updated.

## Editing

- **Click-driven auto zooms:** Cutmark can propose source-aware zooms from recorded screen interactions and apply only reviewed suggestions to a new edit version.
- **Stable zoom rendering:** zooms map through the real frame-rounded cut, including reused screen ranges, while preserving output size, duration, cover behavior, and existing overlays.
- **Smart-speed analysis:** Cutmark can identify conservative 1.5× candidates only when ScreenCaptureKit reports visual idle and screen-clock audio evidence is silent. This release keeps smart-speed read-only; it does not retime media yet.

## Recording evidence

- **Append-only screen event evidence:** Camera + Screen recording can persist normalized pointer movement, clicks, scrolls, manual markers, and ScreenCaptureKit visual active/idle transitions alongside the take.
- **Privacy boundary:** the event format does not capture keystrokes, and smart-speed never treats missing pointer activity as proof that the screen is idle.
- **Screen-clock audio timing:** camera + screen takes prepare the screen movie's own word/sound timing so editing decisions do not translate timestamps from another source clock.

## Release security

- **Verified update downloads:** Cutmark checks the SHA-256 digest published by GitHub before mounting a downloaded release DMG.
- **Developer ID distribution:** production builds are signed with hardened runtime and secure timestamps, then the DMG is signed, notarized by Apple, stapled, and checked with Gatekeeper before publication.
- **Publisher-bound updates:** once running a production-signed build, Cutmark requires future updates to carry a stapled notarization ticket and the same Apple Team ID before removing quarantine or staging the app.

## Platform

Cutmark 0.2.0 is a **macOS 15+ Apple silicon** release. The iPhone companion remains outside the public macOS release path.

## Install

Download `Cutmark.dmg` from this release, open it, and drag `Cutmark.app` to Applications.
