# Studio

Product demos with a quiet dark frame and a crisp blue accent.

## Direction

Dark frames, generous margins, simple sans-serif titles. Use one restrained push-in only when it helps explain a click.

## Editing

Preserve the speaker’s meaning. Cut mistakes only after reviewing the take. Leave room around sentences. Do not add music, stock footage, or generated images without a request.

## Frame and captions

Use tokens.json for colours and type. Keep all text inside a 7% safe margin. Captions are optional and must use the actual transcript, at least 42 px at 1080p. Never stretch source footage. Preview the final render before delivery.

## Preview

preview.png is a designed style sample, not a processed user recording. Selecting this style supplies a guide to the editing assistant; it does not apply a live filter to the native cut preview.
