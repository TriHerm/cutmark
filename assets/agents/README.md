# Agent marks

The real marks of the agents Takes can run or connect, shown on Settings › Agents and in the
chat's agent card. Each mark belongs to its owner; Takes shows it only to name that agent.

| File | Agent | Source |
|---|---|---|
| claude.svg | Claude Code, Claude Desktop | Simple Icons `claude` (Anthropic's Claude mark), drawn in #D97757 |
| openai.svg | Codex | Simple Icons `openai` (OpenAI's Codex pages use this mark) |
| cursor.svg | Cursor | Simple Icons `cursor` |
| gemini.svg | Gemini CLI | Google's Gemini sparkle, gstatic.com/lamda/images/gemini_sparkle_v002 |
| antigravity.png | Antigravity | antigravity.google/favicon.svg without its round background, drawn by WebKit (its blur gradient does not draw in NSImage) |
| opencode.svg | opencode | Simple Icons `opencode` |
| pi.svg | pi | pi.dev/favicon.svg, light-mode fill |

Fetched 2026-10-11. The one-colour marks are drawn as templates in the app's ink (Claude in its orange).
